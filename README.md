# AtCoder Kit

**競技プログラミングで必要な書き方を、すぐ探して参照するための個人用知識集。**

**言語 → 分野 → トピック**で分類する。主役は参照用Markdownで、提出コードや実行可能なパッケージの整備を目的とするものではない。

## Rust

**使う順序：** [テンプレート](rust/template.rs)をベースに書き、[分野別目次](rust/アルゴリズム/README.md)で必要な処理を探す。必要なときだけ[スニペット](rust/スニペット.md)を展開する。事前公開コードと外部出典の扱いは[利用ルール](atcoder/利用ルール.md)を参照。

**[Rust提出テンプレート](rust/template.rs)** — `read<T>()` と空の`main()`を標準搭載。GitHub/AtCoderアカウントと短いコミットURLをActionsで自動記入。末尾にメモ・参考リンク欄。
