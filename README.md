# AtCoder Kit

### 使い方の優先順位

1. **素直なRustコードで短く書けるなら、それを使う。** 例えば `read_s().into_bytes()`、`a.partition_point(...)`、`println!`。
2. よく繰り返す定型文は**エディタのスニペット**にする。ライブラリ化のために余分な関数・構造体を増やさない。
3. 標準API・AtCoder環境のクレート・既存ブログの説明で足りるなら、それらを参照する。
4. **独自の`.rs`ファイルは、再利用・改造・テストの価値がある場合に限る。** 普段の参照はMarkdownに用途別の書き方を並べる。

これまでの`rust/src/` のテストつき実装やScannerは残すが、**それが正解の書き方という扱いにはしない**。
