# AtCoder Kit

**競技プログラミングで必要な処理を短く・分かりやすく書くための個人用知識集。**

ファイル形式や「メモかどうか」ではなく、**言語 → 分野 → トピック**を基本に分類する。

## Rust

**[Rust提出テンプレート](rust/template.rs)** — `read<T>()` と空の`main()`を標準搭載。GitHub/AtCoderアカウントと短いコミットURLをActionsで自動記入。末尾にメモ・参考リンク欄。
