# AtCoder Kit

**自分が理解し、必要なときにコピーして使える競技プログラミング用ライブラリ。**

まずは Rust。アルゴリズムの「名前を知っている」と「自分で使える」を区別しながら、少しずつ増やします。説明や作業記録は原則として日本語で書きます。

> このリポジトリは個人用です。収録するコードは、実際に使う前に自分でも仕様・境界条件を確認します。

## 利用方法

1. [Rustの目次](rust/README.md)でコードを選ぶ。
2. 必要な関数を `.rs` ファイルから提出用コードにコピーする（`use` が必要な場合は一緒にコピー）。
3. コンテスト中に生成AI製コードをコピーする場合は、[AtCoderの現行ルール](docs/AtCoderで使うときの注意.md)に従って**コンテスト前から公開されたコードの固定コミットURL**を提出コードへ添付する。
4. ライブラリ変更時は、`cd rust && cargo test && cargo fmt --check` で確認する。

## 実際に使っている道具

問題を解く際は `cargo-compete` と自作の `ac-test` を併用し、`proconio` などのスニペットも使います。初期の外部クレートなしテンプレートだけが唯一の使い方ではありません。詳しくは [開発環境と使い方](docs/開発環境と使い方.md) を参照してください。
