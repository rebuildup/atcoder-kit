# アルゴリズム解説

すぐに思い出せるように、**何に使うか → 必要条件 → 計算量 → コード**の順で書きます。

## 二分探索

[コードを開く](../rust/src/search/binary_search.rs)

昇順ソート済みの配列で、条件を満たす境界を高速に探します。

- `lower_bound(&a, &x)`: `x` **以上**となる最初の添字
- `upper_bound(&a, &x)`: `x` **より大きい**最初の添字
- どちらも見つからなければ `a.len()`。計算量は O(log n)。

例: `a = [1, 2, 2, 4]` なら、`x = 2` で `lower_bound = 1`、`upper_bound = 3`。

**間違えやすい点:** ソートされていない配列には使えない。戻り値が配列長になるので、結果を添字として使う前に確認する。

## 累積和

[コードを開く](../rust/src/array/prefix_sum.rs)

配列の各位置までの合計を先に用意することで、区間和を O(1) で求めます。

- 元の配列が長さ `n` なら、累積和は長さ `n + 1`。
- `prefix[0] = 0`、`prefix[i + 1] = prefix[i] + a[i]`。
- 半開区間 `[l, r)` の和は `prefix[r] - prefix[l]`。
- 構築 O(n)、各区間和 O(1)。

例: `a = [3, -2, 5]` なら `prefix = [0, 3, 1, 6]`。`[1, 3)` の和は `6 - 3 = 3`。

**間違えやすい点:** `r` を含まないことと、合計が `i64` に収まること。

## 各桁の和

[コードを開く](../rust/src/math/digit_sum.rs)

10で割った余りを加算し、10で割る操作を繰り返します。計算量は O(桁数)。この実装は `u64`（負数なし）です。

## 最大公約数・最小公倍数

[コードを開く](../rust/src/math/gcd_lcm.rs)

最大公約数はユークリッドの互除法を使います。`gcd(a, b)` で両方とも0の場合は0を返します。最小公倍数は `a / gcd(a, b) * b` とし、乗算が `u64` を超える場合は `None` を返します。
