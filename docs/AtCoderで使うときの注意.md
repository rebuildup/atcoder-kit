# AtCoderで使うときの注意

最終確認日: **2026-10-18**。規則は変更される可能性があるため、参加するコンテストの最新ルールを優先します。

## 2026年10月14日版の要点

[AtCoder生成AI対策ルール（日本語）](https://info.atcoder.jp/entry/llm-rules-ja) によると、開催中の ABC / ARC / AGC は生成AIの使用が原則禁止です。コンテスト**開始前**に生成AIを使って用意したコードは、次の条件で使用可能です。

1. コンテスト開始前にWeb上で公開し、生成時期を確認できるようにしておく。
2. コピーして使うときは、参照したコードのURLを添える。

これらは、自作だけでなく他人の生成AI製コードにも適用されます。事前公開と参照URLの条件を満たせば、AI製であるという特別な表記自体は必須ではありません（当該版ルール）。

**練習時**には上記の開催中ルールは適用されません。AHCには別ルールがあります。コードのライセンスは常に確認してください。

## GitHubの固定コミットURLを使う

`main` ブランチのURLはファイル内容が後から変わります。コンテストでの参照には、公開済みの**特定コミットSHAを含む**URLを推奨します。

例（`<公開済みのコミットSHA>` を実際の値で置き換える）:

```text
// 参照URL:
// - https://github.com/rebuildup/atcoder-kit/blob/<公開済みのコミットSHA>/rust/src/search/binary_search.rs
```

同じ提出で複数のコードをコピーしたら、使用したコードのURLをそれぞれ追加します。テンプレートしか使っていない場合も、テンプレートの作成元や必要な出典の扱いをルールに照らして確認してください。

**公開してからコンテストが始まることが重要**です。コンテスト中に新しくAIでコードを生成・修正するためにこのチャットを利用する運用はしません。
