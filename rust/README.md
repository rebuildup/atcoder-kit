# Rust

**使いたい処理を分野から探す**ための入口。

## 提出用テンプレート

**[最小の署名付きテンプレート `template.rs`](template.rs)** — `read<T>()` と空の`main()`、短い出典リンク・GitHub/AtCoderアカウント情報、末尾のメモ・参考リンク欄。

入力は標準の `read<T>()` で空白区切りの値を1つずつ読む。普段は入力関数を追加しない。必要な処理のみ[スニペット一覧](スニペット.md)から追加する。

原本は [`templates/contest.rs`](templates/contest.rs)。`main` 更新時にActionsが短い出典リンク付きの `template.rs` を再生成する。調べた記事・コピー元のURLは末尾の `Notes / refs` に追加する。
