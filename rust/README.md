## 提出用テンプレート

**[最小の署名付きテンプレート `template.rs`](template.rs)** — `read<T>()` と空の`main()`、短い出典リンク・GitHub/AtCoderアカウント情報、末尾のメモ・参考リンク欄。

入力は標準の `read<T>()` で空白区切りの値を1つずつ読む。普段は入力関数を追加しない。必要な処理のみ[スニペット一覧](スニペット.md)から追加する。

原本は [`templates/contest.rs`](templates/contest.rs)。`main` 更新時にActionsが短い出典リンク付きの `template.rs` を再生成する。キット外の参照・コピー元のURLは、必要に応じて末尾の `Notes / refs` に記録する。キット自体の事前公開URLはヘッダーにある。[AtCoder利用ルール](../atcoder/利用ルール.md)で使い分ける。
