# 文字列の区間クエリ：一致開始位置を累積する

文字列 `s` の指定区間に `t` が現れるかを、繰り返し調べる。**一致が始まる位置**を累積和にしておけば、問い合わせごとに文字列を探し直さずに済む。

## 使うコード

[提出テンプレート](../template.rs)に標準搭載された `read<T>()` を使う。入力順は問い合わせ数 `q`、文字列 `s` と `t`、各問い合わせの1-indexedの区間 `[l, r]` とする。文字列はASCIIを想定する。

```rust
fn main() {
    let q: usize = read();
    let s = read::<String>().into_bytes();
    let t = read::<String>().into_bytes();
    let n = s.len();
    let m = t.len();

    let mut p = vec![0usize; n + 1];
    for i in 0..n {
        p[i + 1] = p[i];
        if i + m <= n && &s[i..i + m] == t.as_slice() {
            p[i + 1] += 1;
        }
    }

    for _ in 0..q {
        let l: usize = read();
        let r: usize = read();
        let (l, r) = (l - 1, r - 1);

        let found = if r - l + 1 < m {
            false
        } else {
            let last = r + 1 - m;
            p[last + 1] > p[l]
        };
        println!("{}", if found { "Yes" } else { "No" });
    }
}
```

## 確認するところ

- `p[i]` は先頭から `i` 個分の「`t` と一致する開始位置」の数。初期値は `p[0] = 0`。
- 問い合わせは両端を含む **1-indexedの `[l, r]`** を想定し、先に0-indexedへ変換する。
- `t` の長さが `m` のとき、区間に収まる最後の開始位置は `r + 1 - m`。`usize` では `r - m + 1` と書くと途中でアンダーフローする場合がある。区間長が `m` 未満なら `false`。
- 一致が存在する条件は `p[last + 1] > p[l]`。`p` は減らないので差を計算しなくてもよい。

`m > 0`、入力の添字が有効、`s` / `t` がバイト比較で扱えることが前提。構築は `O(nm)`、各問い合わせは `O(1)`。`m` が小さい問題向け。
