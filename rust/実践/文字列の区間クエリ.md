# 文字列の区間クエリ：一致開始位置を累積する

文字列 `s` の指定区間に `t` が現れるかを、繰り返し調べる。**一致が始まる位置**を累積和にしておけば、問い合わせごとに文字列を探し直さずに済む。

## 使うコード

`read_i()`、`read_vi()`、`read_s()` は[入出力スニペット](../基礎/入出力.md)から定義する。`s` と `t` は英数字などをバイト単位で比較する想定。

```rust
fn main() {
    let q = read_i();
    let s = read_s().into_bytes();
    let t = read_s().into_bytes();
    let n = s.len();
    let m = t.len();

    let mut p = vec![0usize; n + 1];
    for i in 0..n {
        p[i + 1] = p[i];
        if i + m <= n && &s[i..i + m] == t.as_slice() {
            p[i + 1] += 1;
        }
    }

    for _ in 0..q {
        let [l, r] = read_vi().try_into().unwrap();
        let (l, r) = (l as usize - 1, r as usize - 1);

        let found = if r - l + 1 < m {
            false
        } else {
            let last = r - m + 1;
            p[last + 1] > p[l]
        };
        println!("{}", if found { "Yes" } else { "No" });
    }
}
```

## 確認するところ

- `p[i]` は先頭から `i` 個分の「`t` と一致する開始位置」の数。`p[0] = 0` とする。
- 問い合わせは両端を含む **1-indexedの `[l, r]`** を想定し、先に0-indexedへ変換する。
- `t` の長さが `m` のとき、区間に収まる最後の開始位置は `r - m + 1`。区間長が `m` 未満なら `false`。
- 一致が存在する条件は `p[last + 1] > p[l]`。`p` は減らないので、差を計算しなくてもよい。

`m > 0`、入力の添字が有効、`s` / `t` がバイト比較で扱えることが前提。構築は `O(nm)`、各問い合わせは `O(1)`。`m` が小さい問題向け。
