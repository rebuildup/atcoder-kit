## 元データから修正したところ

| 接頭辞 | 元データの問題 | 修正 |
| --- | --- | --- |
| `stdrvc` | `Strig::new()` はタイプミス。未importの `io::stdin()` も参照する | `String::new()` と `std::io::stdin()` |
| `s2u` | `$0s` は、変数名を含めた意図した展開にならない | `${1:s}`, `${2:n}` のプレースホルダに置換 |
| `nibun` | `(left + right) / 2` は型の最大値付近でオーバーフローの可能性 | `left + (right - left) / 2` に変更 |
| `proconio` | `main` の中にカーソルの最終位置がない | `$0` を配置 |
| `ketawa` | 定義名が空文字列 | `各桁の和` に変更（接頭辞は同じ） |

**未変更のスニペットも含め、すべてをコンテスト環境で実行検証したわけではない。** 実際に使う前に必要な変数、`use`、依存クレートと入力前提を確認する。

## 二分探索は自作しなくてもよい

昇順配列 `a` と探索値 `x` があるとき:

```rust
let lower = a.partition_point(|&v| v < x);  // x 以上の最初の位置
let upper = a.partition_point(|&v| v <= x); // x より大きい最初の位置
```

標準の `binary_search` は重複要素の「最初」の位置を保証しない。重複があるときの境界を求めるなら `partition_point` を使う。自分の二分探索を理解・実装したい場合は [ライブラリの実装](src/search/binary_search.rs) も参照する。
