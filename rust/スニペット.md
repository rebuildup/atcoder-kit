# Rustスニペット

**用途からコードを探す → 必要なら説明を読む → 展開する。** 覚える接頭辞の数ではなく、問題に必要なコードを少ない手間で書けることを優先する。

## 使い方

- このリポジトリ内の正本は **[rust.json](snippets/rust.json) の1ファイルだけ**。VS Code / CursorのRust言語用ユーザースニペットに内容を登録して使う。**リポジトリを更新しただけではエディタ側の定義は自動更新されない**。
- 普段から覚えるのは自分が繰り返し使うものだけ。ほかは**分野別の資料に接頭辞を記載**しておき、必要なときに調べる。
- スニペットが短くても、そのままRustを書くほうが分かりやすければ使わない。**「毎回スニペットを選ぶこと」を目標にしない。**
- 繰り返し使うコードは展開してから、その場で理解・変更できる状態を優先する。

## 用途から探す

| したいこと | スニペット | 使い方・注意 |
| --- | --- | --- |
| 数値・文字列を標準入力から読む | スニペット不要 | [入出力](基礎/入出力.md)。テンプレートの `read<T>()` を使う |
| 旧来の1行読み取り関数 | `stdri`、`stdru`、`stdrs`、`stdrvi`、`stdrvs`、`stdrvc` | 既存コード用。新規では不要、`read<T>()` と混用しない |
| 旧入力関数に依存する展開 | `stdrb`、`stdr2`、`s2u` | `read_s` / `read_vi` を使う既存コード用。新規は `read<T>()` を使う |
| AtCoderのマクロ入力 | `proconio`、`input`、`inn`、`innm`、`innmk`、`invn`、`invnm` | [proconioの利用条件](../atcoder/環境とツール.md#入力の3方式) / [例](templates/proconio.rs)。依存クレートが必要 |
| 答え・Yes/Noを出力 | `ANS`、`YES`、`NO`、`YN`、`pl` | [出力](基礎/入出力.md#出力)。`ANS` は変数名を指定、`pl` は式を含めた値の出力に使う |
| グリッドの到達判定（時間・座標） | `gridvisit` | [到達可能性と偶奇](アルゴリズム/グリッド/到達可能性と偶奇.md)。毎秒必ず隣接マスへ1歩、障害物なし |
| 二分探索のループ | `nibun` | [二分探索](アルゴリズム/探索/二分探索.md)。まず`partition_point`と比較 |
| 累積和の構築 | `pfxsum` | [累積和](アルゴリズム/配列/累積和.md)。`i64`の配列を想定 |
| HashSetの宣言・初期化 | `hashset` / `hset` | [HashSet](基礎/HashSet.md)。`use`と`HashSet::new()`を展開 |
| 旧行入力でn個の異なる値を数える | `hsetn`（互換用） | [HashSet](基礎/HashSet.md)。`n`と`read_i()`が必要。新規は`hashset`と標準の`read<T>()`を使う |
| 各桁の和 | `ketawa` | [関数の実装](src/math/digit_sum.rs) |
| ループ・円周率・文字列の一致数 | `repn`、`pi`、`wordmatch` | [Rustの標準API](https://doc.rust-lang.org/std/)も確認。短ければ直接書く |

## まず覚える必要があるものは？

入力はテンプレートにある `read<T>()` を利用する。`stdri` / `stdrvi` / `stdrs` などは過去の解答用として残すが、毎回展開しない。

それ以外も実際に繰り返し使うまで「常用」と断定しない。例えば二分探索は `partition_point` で済むなら `nibun` は不要。

## トピックにスニペットを追加する基準

1. 対象が**数行以上**、または入力・出力のように**実際に何度も書く**。
2. 接頭辞が短く、名前から用途を想像でき、既存のものと衝突しない。
3. **そのトピックのMarkdownに接頭辞と前提を書く**。スニペットしか見つからない状態にしない。
4. 正確なRustを展開でき、不要な`main()`や他の定義を増やさない。
5. 内容が1行で十分簡単な場合は、**コード例のみ**でもよい。

### 例：累積和

[累積和の解説](アルゴリズム/配列/累積和.md)には、手で書くコード・説明・`pfxsum` の接頭辞を同じページに置く。必要なときだけその接頭辞を利用すれば、コードを毎回コピーしに戻る必要がない。

## 設定

[単一の定義ファイル `rust/snippets/rust.json`](snippets/rust.json) をVS Code / Cursorの **Snippets: Configure Snippets → Rust** から開いた`rust.json`に登録する。

以前の`core.json`と`rust.original.json`は廃止。**利用中の定義と資料を一つの正本に揃える**。実際の使用回数はまだ計測していないため、スニペットの件数を「優秀さ」の指標にはしない。
