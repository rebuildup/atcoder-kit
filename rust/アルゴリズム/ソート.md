# ソート：昇順・降順・複数条件で並べる

**整数を小さい順に並べるなら `sort_unstable()` だけでよい。** `Vec` と配列・スライスで使え、`use` も外部クレートも不要。

```rust
let mut a = vec![3, 1, 4, 1, 5];
a.sort_unstable();
// a = [1, 1, 3, 4, 5]
```

`sort_unstable()` は**元の配列を書き換える**。並べ替えた新しい配列を返すわけではないので、`let mut` が必要。要素は `Ord` を実装している必要がある（整数、文字列、整数のタプルなど）。

## 降順（大きい順）

```rust
let mut a = vec![3, 1, 4, 1, 5];
a.sort_unstable_by(|x, y| y.cmp(x));
// a = [5, 4, 3, 1, 1]
```

`cmp` は2つの値の順序を決める比較。`x.cmp(y)` なら昇順、`y.cmp(x)` なら降順になる。

## タプル・複数条件

Rustのタプル `(T, U)` は2つの値を組にして扱う。`p.0` / `p.1` で各要素にアクセスし、`let (x, y) = p;` で分解できる。

```rust
let mut p = (3, 8);
p.1 = 5;
let (x, y) = p; // x = 3、y = 5
```

タプルは**先頭の要素から順番に比較**される。全項目が昇順ならそのまま並べる。

```rust
let mut a = vec![(2, 10), (1, 30), (1, 20)];
a.sort_unstable();
// a = [(1, 20), (1, 30), (2, 10)]
```

**第1要素は昇順、第2要素は降順**という条件なら `Reverse` を使う。

```rust
use std::cmp::Reverse;

let mut a = vec![(2, 10), (1, 30), (1, 20)];
a.sort_unstable_by_key(|&(x, y)| (x, Reverse(y)));
// a = [(1, 30), (1, 20), (2, 10)]
```

`sort_unstable_by_key` は指定したキーで比較する。`Reverse(y)` は `y` だけの順序を逆転させるため、`-y` のように負数への変換をする必要がなく、符号なし整数でも使える。

構造体などの**特定のフィールドを基準に並べたい**ときも、`sort_unstable_by_key(|item| item.score)` のように書ける（ここでは `score` が `Ord` を実装する型であることが前提）。

## 同じキーの元の順番を残す（安定ソート）

`sort_unstable` は**同じキーの要素の相対順序を保証しない**。同点なら入力順を維持したい場合は `sort_by_key`（安定ソート）を使う。

```rust
let mut a = vec![("A", 80), ("B", 90), ("C", 80)];
a.sort_by_key(|&(_, score)| score);
// a = [("A", 80), ("C", 80), ("B", 90)]
```

| API | 同じキーの入力順 | 基本的な使いどころ |
| --- | --- | --- |
| `sort_unstable()` | 保証しない | 値そのもので並べる |
| `sort_unstable_by(...)` | 保証しない | 比較方法を自分で指定する |
| `sort_unstable_by_key(...)` | 保証しない | タプル・フィールドなどをキーにする |
| `sort()` / `sort_by_key(...)` | 維持する | 同順位の入力順が必要 |

どちらも計算量は最悪 `O(n log n)`。`sort_unstable` 系は追加の要素バッファを使わないため、入力順を残す必要がなければまずこちらを検討する。

## 小数を並べる

`f32` / `f64` は `Ord` を実装しないため、`sort_unstable()` を直接使えない。`total_cmp` で順序を指定する。

```rust
let mut a = vec![2.5_f64, -1.0, 0.0];
a.sort_unstable_by(f64::total_cmp);
// a = [-1.0, 0.0, 2.5]
```

`total_cmp` は `NaN` や `-0.0` と `0.0` の間にも順序を定義する。整数のソートとは比較条件が異なることに注意。

## 並べ替えて重複を除く

```rust
let mut a = vec![3, 1, 3, 2, 1];
a.sort_unstable();
a.dedup();
// a = [1, 2, 3]
```

`dedup()` は**隣り合う重複**を取り除く。離れた場所にある同じ値も消したいなら、先にソートする。

## 二分探索につなげる

昇順にした後なら、`partition_point` で値の境界を見つけられる。

```rust
let mut a = vec![4, 1, 2, 2, 3];
a.sort_unstable();
let first_ge_2 = a.partition_point(|&v| v < 2); // 1
```
