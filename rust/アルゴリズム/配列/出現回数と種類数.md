# 出現回数で種類数を管理する（0との境界）

**重複がある値の追加・削除を繰り返しながら「今ある値の種類数」を求める**ときに使う。値が `1..=N` など小さな整数なら、`HashSet` より出現回数の配列 `cnt` が簡単。

## まず考えること

- `cnt[x]` = 値 `x` が現在いくつあるか。
- `kinds` = `cnt[x] > 0` である `x` の個数。
- **削除で `1 → 0` になったときだけ**種類数を `-1`。
- **追加で `0 → 1` になるときだけ**種類数を `+1`。
- `3 → 2` や `1 → 2` など、0をまたがない更新では種類数は変わらない。

### 最小の更新形

`from` の要素を1個取り除き、`to` に1個加える。最初に `cnt` と `kinds` を正しく初期化しておく。

```rust
cnt[from] -= 1;
if cnt[from] == 0 {
    kinds -= 1;
}
if cnt[to] == 0 {
    kinds += 1;
}
cnt[to] += 1;
```

`from` に要素が1個以上あることが前提。`from == to` でも最終結果は正しい（その更新をスキップしてもよい）。

## 実例：日付別の変更をまとめて処理する（ABC464 C）

[ABC464 C - Plumage Palette](https://atcoder.jp/contests/abc464/tasks/abc464_c)：鳥 `i` の色は `D_i` 日目から `A_i` → `B_i` に変化する。各日 `1..=M` の色の**種類数**を出力する。

**見抜く順番：**

1. 種類数のために鳥を毎日すべて数え直すと `O(NM)`。
2. 鳥は変化前は `A_i`、変化後は `B_i`。まず全員が `A_i` の状態から始める。
3. `D_i` が同じ変更を `events[day]` に入れ、日付順に一度ずつ処理する。
4. その日の**すべての変更が終わってから**種類数を出力する。

以下は既存の[提出テンプレート](../../template.rs)の `read<T>()` を使う `main()` の例。

```rust
fn main() {
    let n: usize = read();
    let m: usize = read();
    let mut cnt = vec![0usize; n + 1];
    let mut events = vec![Vec::<(usize, usize)>::new(); m + 1];

    for _ in 0..n {
        let a: usize = read();
        let d: usize = read();
        let b: usize = read();
        cnt[a] += 1;            // 変更前（0日目）の色
        events[d].push((a, b));
    }

    let mut kinds = cnt.iter().filter(|&&c| c > 0).count();

    for day in 1..=m {
        for &(a, b) in &events[day] {
            if a == b {
                continue;        // 色が変わらない鳥
            }
            cnt[a] -= 1;
            if cnt[a] == 0 {
                kinds -= 1;
            }
            if cnt[b] == 0 {
                kinds += 1;
            }
            cnt[b] += 1;
        }
        println!("{kinds}");
    }
}
```

- `D_i = 1` でも、**1日目の出力前**に変更を処理するので正しい。
- 同じ日の複数変更を途中で出力しない。途中の種類数と、その日を観察した種類数は異なる場合がある。
- `A_i = B_i` は無変更として扱える。
- **時間 `O(N + M)`、空間 `O(N + M)`**。各鳥の変更を1度だけ処理する。

## 累積和・HashSetとの使い分け

| 求めたいもの | 考える方法 |
| --- | --- |
| 区間の要素数・合計を何度も聞かれる | [累積和](累積和.md) |
| ある値が何個あるかを管理する | `cnt[x]`（頻度配列） |
| 追加・削除後の異なる値の個数 | `cnt[x]` と `0 ↔ 1` の境界 |
| 値の範囲が大きい・文字列などがキー | `HashMap<値, 個数>`（または座標圧縮） |

**HashSetだけでは、同じ色が複数羽いるときに1羽が去っただけで色を削除できない。** 出現回数を持てば「最後の1つか？」が判定できる。

プラス・マイナスの**差分を日付順に適用する**という発想は有効。ただし種類数は総和ではなく「個数が正の値の数」なので、単一の累積和だけでは求まらない。差分の適用と、0境界での種類数更新を組み合わせる。
