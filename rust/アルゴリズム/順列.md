# next_permutation：辞書順で次の順列へ

**現在の配列より辞書順で次に大きい並び**へ、元の配列を更新する。Rust標準ライブラリにはこの操作を行うAPIがないため、必要なら次の関数をコピーして使う。

```rust
fn next_permutation<T: Ord>(a: &mut [T]) -> bool {
    let n = a.len();
    if n < 2 {
        return false;
    }

    let mut i = n - 2;
    while a[i] >= a[i + 1] {
        if i == 0 {
            a.reverse();
            return false;
        }
        i -= 1;
    }

    let mut j = n - 1;
    while a[j] <= a[i] {
        j -= 1;
    }

    a.swap(i, j);
    a[i + 1..].reverse();
    true
}
```

- `true`：次の順列があり、配列を書き換えた。
- `false`：最後の順列だったため昇順に戻した（空・1要素なら変更なし）。
- `T: Ord`：大小比較できる値に使える。1回 `O(n)`、追加メモリ `O(1)`。

## 使い方

```rust
let mut a = vec![1, 3, 2];
assert!(next_permutation(&mut a));
assert_eq!(a, [2, 1, 3]);

let mut b = vec![3, 2, 1];
assert!(!next_permutation(&mut b));
assert_eq!(b, [1, 2, 3]);
```

**全順列を列挙**するには、先に昇順にソートする。

```rust
let mut a = vec![1, 2, 3];
a.sort_unstable();

loop {
    println!("{a:?}");
    if !next_permutation(&mut a) {
        break;
    }
}
```

この例では `[1, 2, 3]` から `[3, 2, 1]` までの6通りを表示する。重複要素があっても辞書順で異なる並びだけを列挙できる。すべて異なる `n` 要素を列挙する計算量は `O(n × n!)`。

## 仕組み

1. 右から見て `a[i] < a[i + 1]` となる最後の `i` を探す。なければ最後の順列。
2. 右側から `a[i]` より大きい要素を探し、交換する。
3. `i + 1` 以降を反転して、増やした後の並びを最小にする。

例えば `[1, 3, 2]` → `[2, 1, 3]` → `[2, 3, 1]`。後ろの部分はもともと降順なので、反転すれば昇順になる。
