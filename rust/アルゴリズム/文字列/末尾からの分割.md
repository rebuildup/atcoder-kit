# 末尾からの文字列分割：ends_with と truncate

**候補の単語を末尾から一意に判別できるなら、後ろから取り除くだけで分割を確認できる。** 例えば ABC049 C「Daydream」では `dream` / `dreamer` / `erase` / `eraser` の4語を使う。

## 使うコード

[提出テンプレート](../../template.rs)に標準搭載された `read<T>()` を使う。次の `main()` をテンプレートと合わせて使える。

```rust
fn main() {
    let mut s: String = read();

    while !s.is_empty() {
        let mut found = false;

        for word in ["dream", "dreamer", "erase", "eraser"] {
            if s.ends_with(word) {
                s.truncate(s.len() - word.len());
                found = true;
                break;
            }
        }

        if !found {
            println!("NO");
            return;
        }
    }

    println!("YES");
}
```

**使い方：** 文字列の末尾に4語のいずれかがあれば取り除く。どれも一致しなければ `NO`、全て取り除けたら `YES`。

## 新しく使う文字列の操作

```rust
let mut s = String::from("dreamerase");

let matches = s.ends_with("erase"); // true
s.truncate(s.len() - "erase".len());
// s は "dream"
```

- `ends_with(word)`：`String` の末尾が `word` に一致するか調べる（戻り値は `bool`）。
- `truncate(len)`：`String` を**先頭から指定したバイト数**まで短くする。元の `String` が変化する。
- `is_empty()`：空文字列になったか確認する。
- `break` は単語を1つ取り除いたときに内側の `for` を抜ける。`return` は失敗が決まったときに `main` を終了する。

`truncate` はUTF-8の**文字境界**以外を指定するとパニックする。この問題は英小文字だけなので、`s.len() - word.len()` で文字境界を壊さない。

## なぜ前からではなく後ろからか

`dream` は `dreamer` の先頭に一致し、`erase` も `eraser` の先頭に一致する。前から短い方を先に消すと、単語の途中を残してしまう。

一方この4語は、**どの語も他の語の末尾にならない**。末尾に一致する単語は高々1つなので、後ろからなら選び間違えない。これはこの問題の単語集合の性質を利用した貪欲法。

一般の単語集合では末尾に複数候補が重なることがある。その場合は、分岐を探索するか `dp[i]`（先頭 `i` 文字まで分割できるか）などのDPを考える。

候補が4語に固定され、1回の比較は最長7文字、取り除くたび文字列が短くなるので、今回の計算量は文字列長を `L` として `O(L)`、追加領域は定数（入力文字列を除く）。
