# 素数判定・高速べき乗・mod逆元

**素数を1つ判定**する、**べき乗の剰余**を計算する、**素数を法とする割り算**に使う基本数論。提出時は必要な関数だけコピーする。

## 素数判定

```rust
fn is_prime(n: u64) -> bool {
    if n < 2 {
        return false;
    }
    if n % 2 == 0 {
        return n == 2;
    }
    let mut d = 3;
    while d <= n / d {
        if n % d == 0 {
            return false;
        }
        d += 2;
    }
    true
}
```

- 合成数 `n = a * b` には、少なくとも一方が `√n` 以下の約数がある。よって **`√n` まで**調べればよい。
- 偶数を先に処理し、奇数の候補だけ試す。`d <= n / d` なら `d * d` のオーバーフローを避けられる。
- `0` と `1` は素数ではない。`is_prime(121)` は `false`（11×11）。
- 時間 `O(√n)`、追加メモリ `O(1)`。**多数の整数をまとめて調べる場合**は、別手法のエラトステネスの篩を検討する。

## 二分累乗法：`a^e mod m`

```rust
fn mod_pow(mut a: u64, mut e: u64, m: u64) -> u64 {
    let mut ans = 1 % m;
    a %= m;
    while e > 0 {
        if e & 1 == 1 {
            ans = (ans as u128 * a as u128 % m as u128) as u64;
        }
        a = (a as u128 * a as u128 % m as u128) as u64;
        e >>= 1;
    }
    ans
}
```

- 指数を2進数で見て、立っているビットに対応する `a, a², a⁴, ...` を答えに掛ける。毎回 `a` を2乗し、指数を半分にする。
- `2^10 mod 7 = 2`。`e = 0` なら `1 % m` を返す。
- 前提は **`m > 0`**。乗算は `u128` に拡張してから剰余を取り、`u64` のオーバーフローを避ける。
- 時間 `O(log(e + 1))`、追加メモリ `O(1)`。

## 素数modの逆元：`a^(p-2) mod p`

法 `p` が**素数**で `a % p != 0` なら、フェルマーの小定理から `a^(p-1) ≡ 1 (mod p)`。したがって逆元は `a^(p-2) mod p`。直前の `mod_pow` を再利用する。

```rust
fn mod_inv(a: u64, p: u64) -> u64 {
    mod_pow(a, p - 2, p) // pは素数、a % p != 0
}
```

- `mod_inv(4, 7) = 2`。実際、`4 * 2 % 7 = 1`。
- 割り算 `x / a (mod p)` は `x * mod_inv(a, p) % p`（積のオーバーフローに注意）。例：`5 / 3 (mod 7) = 5 * 5 % 7 = 4`。
- **合成数modにそのまま適用しない**。一般に逆元が存在するのは `gcd(a, m) = 1` の場合。GCDは[既存の実装](../../src/math/gcd_lcm.rs)を参照。
- 計算量は `mod_pow` と同じ `O(log p)`。

## 呼び出し例

上の3関数を同じソースに置いたとき：

```rust
fn main() {
    println!("{}", is_prime(121)); // false
    println!("{}", mod_pow(2, 10, 7)); // 2
    println!("{}", mod_inv(4, 7)); // 2
}
```

素数判定・二分累乗法・逆元をそれぞれ必要なときだけ追加する。複数の法に対する逆元が必要なら、その法で逆元が存在する条件を先に確認する。
