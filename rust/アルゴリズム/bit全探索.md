# bit全探索：各位置の「する・しない」を試す

**使いどころ：** 要素を「選ぶ／選ばない」、数字の間を「区切る／区切らない」、スイッチを「ON／OFF」など、**独立した2択が少数あるとき**。全部の組み合わせを調べられる。

## まず、bitを使わずに考える

3個のスイッチがあれば、各スイッチはONかOFFの2択。全体では `2 × 2 × 2 = 8` 通り。

この1通りを整数 `mask` で表す。

- `0` のbit = OFF（選ばない）
- `1` のbit = ON（選ぶ）
- **右端のbitがbit 0**。配列ならbit 0と`a[0]`を対応させる、と最初に決める。

| mask（2進数） | bit 2 | bit 1 | bit 0 | 選ぶ要素（添字） |
| --- | --- | --- | --- | --- |
| `000` | 0 | 0 | 0 | なし |
| `001` | 0 | 0 | 1 | 0 |
| `010` | 0 | 1 | 0 | 1 |
| `011` | 0 | 1 | 1 | 0, 1 |
| `100` | 1 | 0 | 0 | 2 |
| `101` | 1 | 0 | 1 | 0, 2 |
| `110` | 1 | 1 | 0 | 1, 2 |
| `111` | 1 | 1 | 1 | 0, 1, 2 |

`mask` を0から7まで増やすだけで8通りを列挙できる。

## Rustの最小パターン

`k` 個の2択があるときは `2^k` 通り。`1usize << k` が `2^k` を表す。

```rust
let k = 3;
for mask in 0..(1usize << k) {
    for i in 0..k {
        if (mask >> i) & 1 == 1 {
            // i番目の選択は「する」
        } else {
            // i番目の選択は「しない」
        }
    }
    // ここでmask 1通り分の判定・集計
}
```

- `mask >> i`：`i` 個右へずらし、確認したいbitを一番右へ持ってくる。
- `& 1`：一番右のbitだけ取り出す。結果は0か1。
- `(mask >> i) & 1 == 1`：`i` 番目が1かどうか調べる。
- 同じ判定は `mask & (1usize << i) != 0` と書くこともできる。
- 内側のループが**どの選択肢（位置）か**、外側が**どの組み合わせか**を表す。

例：`mask = 0b101` のとき、`(mask >> 1) & 1` は `0`、`(mask >> 2) & 1` は `1`。

## 応用1：部分集合を選ぶ（選ぶ・選ばない）

`a = [2, 3, 5]` から、合計が5になる選び方を数える。

```rust
let a = [2, 3, 5];
let n = a.len();
let mut answer = 0;

for mask in 0..(1usize << n) {
    let mut sum = 0;
    for i in 0..n {
        if (mask >> i) & 1 == 1 {
            sum += a[i];
        }
    }
    if sum == 5 {
        answer += 1;
    }
}
assert_eq!(answer, 2); // {2, 3} と {5}
```

重要なのは、**bitが1なら何をするか**を問題ごとに決めること。ここでは「その要素を合計に加える」。

空集合も列挙される。ちょうど`r`個を選びたいなら、内側で計算する前に `if mask.count_ones() as usize != r { continue; }` で除外できる。

## 応用2：数字の間に + を入れる（区切る・区切らない）

[ABC045 C - たくさんの数式](https://atcoder.jp/contests/abc045/tasks/arc061_a)

例：`1234` には4桁あるが、**数字と数字の間は3か所**しかない。

```text
数字    1   2   3   4
隙間      0   1   2    ← bit番号（左から割り当てる）
```

- bit 0：`1`と`2`の間
- bit 1：`2`と`3`の間
- bit 2：`3`と`4`の間
- bitが1ならその隙間に`+`、0ならつなげる。

| mask | できる式 |
| --- | --- |
| `0b000` | `1234` |
| `0b001` | `1+234` |
| `0b010` | `12+34` |
| `0b100` | `123+4` |
| `0b101` | `1+23+4` |
| `0b111` | `1+2+3+4` |

**注意：2進数表記は右からbit 0だが、この問題では文字列の左から1番目の隙間をbit 0に割り当てている。** 表の見た目と対応を取り違えないこと。

### 数字を組み立てて計算する

`+`がなければ、今までの数字を10倍して次の1桁を足す。

- `1` を読む → `current = 1`
- `2` を読む → `current = 1 * 10 + 2 = 12`
- ここで`+`なら、`sum += 12`、`current = 0`
- `5` を読む → `current = 5`
- 最後の数字は、ループを抜けたあとに`sum`へ足す

```rust
// read<T>() はこのリポジトリの提出テンプレートを使用
let s = read::<String>().into_bytes();
let n = s.len(); // この問題では n >= 1
let mut answer = 0u64;

for mask in 0..(1usize << (n - 1)) {
    let mut current = 0u64; // 今つくっている数

    for i in 0..n {
        let digit = u64::from(s[i] - b'0');
        current = current * 10 + digit;

        // 最後の桁の「右側」には隙間がない
        if i + 1 < n && (mask >> i) & 1 == 1 {
            answer += current; // 数を確定
            current = 0;       // 次の数を作り始める
        }
    }

    answer += current; // 最後の数には後続の + がない
}

println!("{answer}");
```

- `s[i]` は数値でなくASCIIのバイトなので、`s[i] - b'0'` で0～9に変換する。
- `current * 10 + digit` は「桁を右につなぐ」操作。
- `(n - 1)` は隙間の数。`n` 個の数字そのものを選ぶ問題ではない。
- この問題での合計は大きくなるため`u64`を使う。

自分で確認：`s = "125"` なら4通り（`125`、`1+25`、`12+5`、`1+2+5`）の合計は`176`。`s = "1234"`、`mask = 0b101` は`1+23+4`。

## 応用3：スイッチのON/OFFを試す

[ABC128 C - Switches](https://atcoder.jp/contests/abc128/tasks/abc128_c)

`n` 個のスイッチをON/OFFする組み合わせを全部試し、各電球につながる**ONのスイッチの個数の偶奇**が指定と一致するかを調べる。

```rust
// read<T>() は提出テンプレートにあるものを使用
let n: usize = read();
let m: usize = read();

let mut lamps = Vec::new();
for _ in 0..m {
    let k: usize = read();
    let connected: Vec<usize> =
        (0..k).map(|_| read::<usize>() - 1).collect(); // 1始まり -> 0始まり
    lamps.push(connected);
}
let p: Vec<usize> = (0..m).map(|_| read()).collect();

let mut answer = 0;
for mask in 0..(1usize << n) {
    let ok = (0..m).all(|j| {
        let on = lamps[j].iter()
            .filter(|&&i| (mask >> i) & 1 == 1)
            .count();
        on % 2 == p[j]
    });
    if ok {
        answer += 1;
    }
}
println!("{answer}");
```

ここでも`mask`の意味は同じ。ただし「選ぶ」は「スイッチをONにする」と読み替える。1つの`mask`が全電球の条件を満たしたら、答えを1増やす。

## 応用4：2グループへの振り分け

`n` 人をAかBに分ける場合も2択。bit 0ならA、bit 1ならBに入れる。`mask = 0b101` （3人）なら、0番目と2番目がB、1番目がA。

`mask.count_ones()` でBの人数が分かる。例えば「Bをちょうど2人にする」「Bの合計コストが上限以下」といった条件を追加できる。

## 何をbitで表すか迷ったら

1. **1通りの答えを決めるための2択は何か？**（要素／隙間／スイッチ／人など）
2. **その2択は何個か？**（`n` 個の要素なら`n`、`n` 桁の隙間なら`n-1`）
3. **bitが0／1の意味は？**（先に決める）
4. **1つのmaskで何を計算するか？**（合計、式の値、条件の真偽など）
5. **全maskの結果をどうまとめるか？**（個数、最大値、総和など）

| よくある混乱 | 確認すること |
| --- | --- |
| `mask` と `i` が混ざる | `mask` = 選び方全体、`i` = その中の何番目を見るか |
| `1 << n` か `1 << (n-1)` か | 選ぶ対象は「要素」か「隙間」か |
| `mask >> i & 1` の意味が曖昧 | `i`番目のbitだけ取り出して0/1を見る |
| 最後の数字が合計に入らない | 区切りの処理とは別に最後の`current`を足す |
| 数字を文字列のまま扱ってしまう | ASCII数字を`s[i] - b'0'`で変換 |
| 組み合わせを全部試すと間に合わない | 計算量を先に見積もる |

## 計算量と注意点

`k` 個の2択は`2^k`通り。各組み合わせで`O(k)`の計算をすれば、全体は`O(k × 2^k)`、追加メモリは`O(1)`（入力配列は別）。

`k = 20` でも約100万通り。`k = 40` だと約1兆通りになるため、bit全探索では現実的でないことが多い。制約から実行可能か判断する。

Rustの`usize`のビット幅以上のシフトはできない。`k < usize::BITS` を前提にする（64bit環境なら`k < 64`）。実際にはビット幅よりも計算時間の制約が先に問題になる。

ほかの全探索方法は[全探索](全探索.md)、基本のビット演算は[ビット操作](../基礎/ビット操作.md)へ。
