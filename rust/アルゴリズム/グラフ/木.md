# 木：根・親・深さ・2頂点間の距離

**木は連結で閉路のない無向グラフ**。頂点数が `n` なら辺数は `n - 1` 本で、異なる2頂点を結ぶ単純経路は必ず1つ。根を1つ決めると、親・子・深さが定義できる。

## Rust：根付き木にして距離を求める

既存の[DFS](DFS.md)と同様に隣接リストを使う。木では**親へ戻る辺を除く**ことで、反復DFSで親と深さを決められる。以下は無向辺を両方向に登録し、頂点0を根とする。

```rust
fn tree_parent_depth(g: &[Vec<usize>], root: usize) -> (Vec<usize>, Vec<usize>) {
    let n = g.len();
    let mut parent = vec![usize::MAX; n];
    let mut depth = vec![0usize; n];
    let mut stack = vec![root];
    parent[root] = root; // 根自身を親にする約束

    while let Some(v) = stack.pop() {
        for &to in &g[v] {
            if to == parent[v] {
                continue;
            }
            parent[to] = v;
            depth[to] = depth[v] + 1;
            stack.push(to);
        }
    }
    (parent, depth)
}

// 2頂点の深さをそろえ、共通祖先まで親をたどる
fn tree_distance(mut u: usize, mut v: usize, parent: &[usize], depth: &[usize]) -> usize {
    let mut dist = 0;
    while depth[u] > depth[v] {
        u = parent[u];
        dist += 1;
    }
    while depth[v] > depth[u] {
        v = parent[v];
        dist += 1;
    }
    while u != v {
        u = parent[u];
        v = parent[v];
        dist += 2;
    }
    dist
}

fn main() {
    let n = 5;
    let edges = [(0, 1), (0, 2), (2, 3), (2, 4)];
    let mut g = vec![vec![]; n];
    for (u, v) in edges {
        g[u].push(v);
        g[v].push(u);
    }

    let (parent, depth) = tree_parent_depth(&g, 0);
    println!("{depth:?}"); // [0, 1, 1, 2, 2]
    println!("{}", tree_distance(3, 1, &parent, &depth)); // 3
}
```

- `depth[v]` は**根から頂点vまでの辺数**。`tree_distance(u, v)` は**uからvまでの辺数**で、根を経由しない経路もある。例：`3 → 2 → 0 → 1` は3本。
- この例は **`n >= 1`、入力が木、頂点番号が`0..n`内**であることが前提。一般の閉路のあるグラフなら、親の判定だけでは足りず訪問済み管理が必要。
- `tree_parent_depth` は各頂点と辺を1度ずつ処理し、時間 `O(n)`、親・深さ・スタックの追加メモリ `O(n)`。
- `tree_distance` は1回 `O(h)`（`h`は根からの最大深さ、最悪`O(n)`）、追加メモリ`O(1)`。大量の距離クエリなら最近共通祖先（LCA）の前処理が候補となる。
- 根からの距離だけ必要なら既存の[BFS](BFS.md)も利用できる。辺に重みがある場合は、辺数ではなく重みの合計を別途計算する。
