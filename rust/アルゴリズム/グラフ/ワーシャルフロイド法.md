# ワーシャルフロイド法：全頂点間の最短距離

**すべての出発点からすべての到着点への最短距離**を同時に求める。1つの始点から求める[BFS](BFS.md)・[ダイクストラ法](ダイクストラ法.md)と用途が異なる。辺の重みが負でも使えるが、**負閉路がある場合は有限の最短距離が定義できない組がある**。

## そのまま使うRust例（有向グラフ）

```rust
fn main() {
    let n = 4;
    let inf = i64::MAX / 4;
    let mut dist = vec![vec![inf; n]; n];

    for i in 0..n {
        dist[i][i] = 0;
    }

    // (出発, 到着, コスト)
    let edges = [
        (0, 1, 3_i64),
        (0, 2, 10),
        (1, 2, 2),
        (1, 3, 9),
        (2, 3, 4),
    ];
    for (u, v, w) in edges {
        dist[u][v] = dist[u][v].min(w);
        // 無向グラフなら dist[v][u] も同様に更新
    }

    for k in 0..n {
        for i in 0..n {
            for j in 0..n {
                if dist[i][k] == inf || dist[k][j] == inf {
                    continue;
                }
                dist[i][j] = dist[i][j]
                    .min(dist[i][k] + dist[k][j]);
            }
        }
    }

    println!("{:?}", dist[0]); // [0, 3, 5, 9]
    println!("{}", dist[3][0] == inf); // true（到達不能）
    let has_negative_cycle = (0..n).any(|v| dist[v][v] < 0);
    println!("{has_negative_cycle}"); // false
}
```

## 状態と更新の意味

- `dist[i][j]` は「頂点`i`から頂点`j`への、現時点で分かっている最小コスト」。初期値は`dist[i][i] = 0`、直接辺があればそのコスト、ほかは`inf`。
- **中継地点`k`を通るほうが安いか**を比較する：`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`。
- `k`を最外側で回すのが重要。`k`までの頂点だけを中継に使ってよい状態へ、順番に広げていく。
- 例では0→2の直接コスト10が、0→1→2の`3 + 2 = 5`に改善する。0→3は0→1→2→3の`3 + 2 + 4 = 9`。
- 有向グラフは一方向だけ登録する。無向グラフなら`dist[v][u]`にも同じコストを登録する。同じ始点・終点の辺が複数ある場合に備え、初期化では`min`を使う。

## 到達不能・負の重み・計算量

- `dist[i][j] == inf`なら**iからjへ到達できない**。無限大の代わりに大きな整数を使っているので、計算前に`inf`の値を足さないようにする。
- **負の辺は許容**するが、負閉路があると一部の組ではコストをいくらでも下げられる。計算後にいずれかの`dist[v][v] < 0`なら負閉路が存在する。負閉路がある場合、得られた距離行列を通常の最短距離表として扱わない。
- 途中の加算が`i64`に収まり、扱う有限の経路コストが`-inf`から`inf`の間に収まる入力を前提とする。極端な重みでは番兵値やオーバーフロー対策を見直す。
- 時間`O(V³)`、追加メモリ`O(V²)`。頂点数が小さく、任意の2頂点間の距離を何度も調べたいときに向く。始点が1つで非負辺なら[ダイクストラ法](ダイクストラ法.md)などを検討する。
