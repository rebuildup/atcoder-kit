# クラスカル法：最小全域木（MST）

**無向グラフの全頂点を、辺のコスト合計が最小になるようにつなぐ**。コストの小さい辺から確認し、**すでにつながっている頂点同士の辺は採用しない**。閉路判定には既存の[Union-Find（DSU）](Union-Find.md)を使う。

## Rust：辺をソートして結合する

次のコードは[Union-Findの `struct Dsu` と `impl Dsu`](Union-Find.md#rust経路圧縮--union-by-size)を同じ提出ソースに置いて使う。**DSU実装はここでは重複掲載しない。**

```rust
fn main() {
    let n = 4;
    // (コスト, 頂点u, 頂点v)：無向辺は1本につき1回だけ登録
    let mut edges = vec![
        (1_i64, 0, 1),
        (2, 1, 2),
        (3, 0, 2),
        (4, 2, 3),
        (5, 1, 3),
    ];
    edges.sort_unstable();

    let mut dsu = Dsu::new(n);
    let mut total = 0_i64;
    let mut used = 0usize;
    for (cost, u, v) in edges {
        if !dsu.same(u, v) {
            dsu.unite(u, v);
            total += cost;
            used += 1;
            if used == n - 1 {
                break;
            }
        }
    }

    if used == n - 1 {
        println!("{total}"); // 7（辺0–1、1–2、2–3）
    } else {
        println!("全頂点をつなげない");
    }
}
```

- `edges.sort_unstable()` はタプルの**先頭のコスト**から比較する。同じコストの場合は頂点番号も比較されるが、どの最小全域木を選ぶかが変わっても最小合計コストは同じ。[ソートの説明](../ソート.md#タプル複数条件)を参照。
- `dsu.same(u, v)` が`true`なら、すでに同じ連結成分なので、その辺を追加すると閉路になる。採用しない。
- `false`なら辺を採用して`unite`し、合計と採用本数を更新する。この例ではコスト3の辺`0–2`は不採用で、`1 + 2 + 4 = 7`。
- **連結した`n`頂点の全域木は辺が`n-1`本**。採用本数がそこに達したら終了できる。最後まで達しなければグラフが非連結で、全域木は存在しない（選んだ辺は最小全域森をなす）。

## 条件・計算量・使い分け

- **無向グラフ**が対象。コストが負でも使用できる。自己ループはDSUの所属判定で不採用、同じ2頂点間の複数辺も扱える。
- **最小全域木は最短経路木とは異なる**。道路網全体の建設コストを最小化する問題に向く。始点からの最短距離は[ダイクストラ法](ダイクストラ法.md)などを使う。
- 頂点数`V`、辺数`E`でソート`O(E log E)`、DSUの操作`O(E α(V))`、初期化`O(V)`、合計`O(V + E log E + E α(V))`。辺とDSUの保存に`O(V+E)`メモリを使う。
- 例は`n >= 1`、頂点番号が`0..n`、コスト合計が`i64`に収まることを前提とする。実問題で必要なら採用した辺も`Vec`に記録できる。
