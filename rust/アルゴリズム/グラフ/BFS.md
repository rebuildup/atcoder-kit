# BFS（幅優先探索）：重みなしグラフの最短距離

**始点に近い頂点から順番に調べる**。各辺の移動コストが同じ（1辺で距離1）なら、最初に見つけた距離が最短距離になる。

## 最短距離を求める

```rust
use std::collections::VecDeque;

fn main() {
    let g = vec![
        vec![1, 2], // 頂点0から1・2へ
        vec![0, 3], // 頂点1から0・3へ
        vec![0],    // 頂点2から0へ
        vec![1],    // 頂点3から1へ
    ];
    let start = 0;
    let mut dist = vec![-1_i64; g.len()];
    let mut q = VecDeque::new();
    dist[start] = 0;
    q.push_back(start);

    while let Some(v) = q.pop_front() {
        for &to in &g[v] {
            if dist[to] == -1 {
                dist[to] = dist[v] + 1;
                q.push_back(to);
            }
        }
    }
    println!("{dist:?}"); // [0, 1, 1, 2]
}
```

- `g[v]` は「頂点 `v` から移動できる頂点番号の一覧」。表し方は[DFSの隣接リスト](DFS.md#隣接リスト)と同じ。
- `VecDeque` は先入れ先出しのキュー。`push_back(to)` で追加し、`pop_front()` で古いものから取り出す。[キュー操作の説明](../../基礎/VecDeque.md)。
- `dist[v]` は始点から `v` までの辺の本数。`-1` は**未発見**を表し、探索終了時にも `-1` なら**到達できない**。始点自身の距離は0。
- 頂点を**キューに追加する時点**で `dist[to]` を更新するので、同じ頂点を重複して追加しない。
- この例の取り出し順は `0 → 1 → 2 → 3`。頂点3には `0 → 1 → 3` で到達するため、距離2。

## 成り立つ条件と計算量

キューは距離0、1、2、…の順に頂点を処理する。このため、**全辺のコストが等しいグラフ**で最短距離を保証できる。辺に異なる非負の重みがある場合はダイクストラ法などを検討する。

- 隣接リストを用いる場合、時間 `O(V + E)`（頂点数 `V`、辺数 `E`）。
- `dist` とキューの追加メモリは `O(V)`。始点番号とすべての移動先番号は `0..g.len()` の範囲内であること。
- [DFS](DFS.md)は深く進み、到達判定・連結成分などに使う。BFSは距離の小さい順に進み、重みなし最短距離を求められる。
