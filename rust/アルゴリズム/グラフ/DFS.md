# DFS（深さ優先探索）

グラフの頂点を深くたどり、行き止まりで戻る探索方法。訪問済みの頂点は再訪問しない。

## 隣接リスト

```rust
let g = vec![
    vec![1, 3], // 頂点0から1と3
    vec![0, 2], // 頂点1から0と2
    vec![1],    // 頂点2から1
    vec![0],    // 頂点3から0
];
```

`g[v]` は「頂点 `v` から直接移動できる頂点の一覧」。`g[0]` なら `[1, 3]` なので、0から1と3へ移動できる。無向グラフの辺は両方向に登録する（`g[u].push(v)` と `g[v].push(u)`）。

## 再帰によるDFS

現在の頂点を訪問済みにし、未訪問の隣接頂点へ再帰的に進む。
