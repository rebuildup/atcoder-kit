# ダイクストラ法：非負コストの最短経路

**辺のコストがすべて0以上のグラフ**で、始点から各頂点への最短距離を求める。重みなしグラフの[BFS](BFS.md)と異なり、通過する辺の本数ではなく**コストの合計**を最小化する。

## 最短距離を求める

```rust
use std::cmp::Reverse;
use std::collections::BinaryHeap;

fn main() {
    // g[v] = (移動先の頂点, 移動コスト) の一覧
    let g = vec![
        vec![(1, 4_i64), (2, 10)],
        vec![(0, 4), (2, 2)],
        vec![(0, 10), (1, 2)],
        vec![], // 頂点3には到達できない
    ];

    let inf = i64::MAX / 4;
    let mut dist = vec![inf; g.len()];
    let mut pq = BinaryHeap::new();

    dist[0] = 0;
    pq.push(Reverse((0_i64, 0_usize))); // (現在の距離, 頂点番号)

    while let Some(Reverse((d, v))) = pq.pop() {
        if d != dist[v] {
            continue; // 更新前の古い候補は無視する
        }

        for &(to, cost) in &g[v] {
            let nd = d + cost;
            if nd < dist[to] {
                dist[to] = nd;
                pq.push(Reverse((nd, to)));
            }
        }
    }

    println!("{:?}", &dist[..3]); // [0, 4, 6]
    println!("{}", dist[3] == inf); // true（到達できない）
}
```

- `g[0] = [(1, 4), (2, 10)]` は「頂点0から1へコスト4、2へコスト10で移動できる」。無向辺なら両方向に登録する。
- `dist[v]` は**現時点で見つかった最短距離の候補**。始点だけ0、それ以外は`inf`で初期化する。
- `Reverse((d, v))` で距離が最小の候補を優先する。一般的な[BinaryHeapの使い方](../../基礎/BinaryHeap.md)は既存資料を参照。
- 0→2の直接経路のコスト10より、0→1→2の`4 + 2 = 6`が小さいので`dist[2]`を更新する。
- ヒープ内には更新前の`(10, 2)`が残り得る。`d != dist[v]`なら古い候補なので飛ばす。
- **未確定の頂点のうち暫定距離が最小のもの**を取り出した時点で、その頂点の最短距離が確定する（辺が非負である場合）。
- 探索後も`dist[v] == inf`なら始点から到達できない。

## 条件・計算量・使い分け

- **負の辺があると正しい最短距離を保証できない**。その場合は別のアルゴリズムを検討する。
- 距離・辺のコストは非負で、途中の加算が`i64`に収まり、有限の最短距離が`inf`より小さいことを前提とする。`inf`を超える距離があり得るなら番兵値や加算方法を設計し直す。
- この実装は改善時に新しい候補をヒープへ積む（古い候補は残す）。時間`O((V + E) log(V + E))`、メモリ`O(V + E)`（隣接リスト自体の記憶領域を除いて、距離配列・ヒープの追加領域は`O(V + E)`）。
- 辺のコストがすべて等しい場合は[BFS](BFS.md)のほうが簡潔で、時間`O(V + E)`。グラフの到達だけ調べるなら[DFS](DFS.md)も使える。

この例は頂点番号が`0..g.len()`の範囲内にあること、および始点0が存在することを前提とする。
