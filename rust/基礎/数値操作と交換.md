# 数値操作と交換：abs・min/max・swap

C++ の `abs`・`min/max`・`swap` に相当するRust標準機能。外部クレートは不要。

## 絶対値（abs）

```rust
let x = -12_i64;
let y = x.abs(); // 12

let a = 3_i64;
let b = 10_i64;
let d = a.abs_diff(b); // 7（u64）
```

- 符号付き整数の `.abs()` は絶対値を返す。`i64::MIN` など絶対値を同じ型で表せない値には注意。
- `.abs_diff()` は差の絶対値を符号なし整数で返すので、整数の引き算によるオーバーフローを避けられる。

## 2値の最小・最大（min / max）

```rust
let a = 8;
let b = 3;
let lo = a.min(b); // 3
let hi = a.max(b); // 8
```

2つの値を比較する `a.min(b)` / `a.max(b)` と、配列全体を走査する [`a.iter().min()` / `max()`](Vec.md#最小値最大値とその位置c-の-min_element--max_element) は区別する。

## 値の交換（swap）

```rust
let mut a = 3;
let mut b = 8;
std::mem::swap(&mut a, &mut b); // a = 8, b = 3

let mut v = [10, 20, 30];
v.swap(0, 2); // [30, 20, 10]
```

別々の変数は `std::mem::swap(&mut a, &mut b)`、同じ配列や `Vec` 内の2要素は `v.swap(i, j)` を使う。配列の添字は0始まりで、範囲外はパニックする。いずれも一定時間 `O(1)` で交換できる。
