# ビット操作：ビット数・ビットマスク

1になっているビットを数えるなら `count_ones()`、集合をビットで表すなら**64要素以内は `u64` のビットマスク**が使える。標準機能だけで書ける。

## 1の個数（popcount）

```rust
let x = 13_u64; // 2進数 1101
let ones = x.count_ones(); // 3（u32型）
```

`count_ones()` は立っているビットの個数を `u32` で返す。

## 集合としてのビット操作

```rust
let mut bits = 0u64;
bits |= 1u64 << 1; // 1番目を立てる
bits |= 1u64 << 4; // 4番目を立てる
bits ^= 1u64 << 1; // 1番目を反転して消す
bits |= 1u64 << 2; // 2番目を立てる

let n = bits.count_ones();            // 2
let has_4 = bits & (1u64 << 4) != 0;  // true（bool）
let value = bits;                     // 20（2進数 10100）
```

| 操作 | 書き方 |
| --- | --- |
| `k` 番目を1にする | `bits |= 1u64 << k;` |
| `k` 番目を0にする | `bits &= !(1u64 << k);` |
| `k` 番目を反転する | `bits ^= 1u64 << k;` |
| `k` 番目を調べる | `bits & (1u64 << k) != 0` |
| 1の個数を数える | `bits.count_ones()` |

- ビット位置は0始まりで、`u64` の場合は `0..64`（0〜63）。64以上のシフトには注意。
- `!= 0` の結果は `bool`。表示すると `1` ではなく `true` になる。
- `u64` の幅は64ビットに固定される。64個を超える場合は必要に応じて `Vec<u64>` などを使う。
