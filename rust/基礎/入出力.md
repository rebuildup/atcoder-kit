# 入力と出力：実際に短く書くためのメモ

**基本は今の `read_i()` / `read_vi()` / `read_s()` を使う。** 特別な仕組みを作る前に、書く行数・読んだときの分かりやすさ・改造しやすさで比較する。

## すぐ探す

| やりたいこと | まず書くもの | 補足 |
| --- | --- | --- |
| 整数を1個読む | `let q = read_i();` | 既存の `stdri` スニペット |
| 1行の整数列を読む | `let a = read_vi();` | 既存の `stdrvi` スニペット |
| 文字列を読む | `let s = read_s();` | 既存の `stdrs` スニペット |
| 文字列をバイト列として受け取る | `let s = read_s().into_bytes();` | `Vec<u8>` が得られる |
| 1行の整数2個を分ける | `let [a, b]: [i64; 2] = read_vi().try_into().unwrap();` | **2個ちょうど**のとき。不要なら元の添字アクセスでもよい |
| 結果を出力する | `println!("{ans}");` | そのまま書くのが最短 |
| Yes/No を出す | `println!("{}", if ok { "Yes" } else { "No" });` | 繰り返すなら `YN` スニペット |
| AtCoder特有の複雑な入力 | `proconio::input!` | 配列、グラフ、`Usize1` など |
| 行数・空白区切りが不規則 | `proconio`、必要なら既存Scanner | むやみにScannerを常用しない |

## 文字列を `as_bytes()` せず受け取りたい

### 実際によく書く形

```rust
let s = read_s();
let sb = s.as_bytes();
```

`as_bytes()` は**コピーをしない**。`&[u8]` として借りる処理なので、これ自体が遅いわけではない。

### 文字列を残す必要がないなら

```rust
let sb = read_s().into_bytes();
let tb = read_s().into_bytes();
```

`into_bytes()` は `String` の所有権を `Vec<u8>` に移し、同じバッファを使う。`s` / `t` を別に保存する必要がない場合は、変数が減って読みやすい。

ただし**日本語などのUTF-8文字列は文字数とバイト数が違う**。文字単位で扱いたいなら `chars()` など別の方法を使う。

## 1行で複数の値を受け取る

### これまでの書き方（間違いではない）

```rust
let lr = read_vi();
let l = lr[0] as usize - 1;
let r = lr[1] as usize - 1;
```

### 個数がちょうど2個なら

```rust
let [l, r]: [i64; 2] = read_vi().try_into().unwrap();
let (l, r) = (l as usize - 1, r as usize - 1);
```

`try_into()` は `Vec` を2要素の配列に変換する。個数が2以外なら `unwrap()` で失敗する。**入力形式で2個と保証されるときだけ**使う。変数の変換処理が増えるなら、元の書き方のほうが分かりやすいこともある。

`proconio` が使える場合は、`input! { l: usize, r: usize }` や `input! { l: Usize1, r: Usize1 }` のように直接宣言できる。ただし依存クレートが必要。

## Yes / No / 答えの出力

### 特に定義を増やさないなら

```rust
println!("{}", if ok { "Yes" } else { "No" });
println!("{ans}");
```

### 同じ操作を繰り返すなら関数にする

```rust
fn ans(ok: bool) {
    println!("{}", if ok { "Yes" } else { "No" });
}

// main内
ans(prefix[last + 1] > prefix[l]);
```

### エディタのスニペットなら

[`rust/snippets/rust.json`](../snippets/rust.json) に次を用意した。展開後は普通のRustコードになる。

| プレフィックス | 展開内容 |
| --- | --- |
| `ANS` | `println!("{}", ans);` （変数名を選択可能） |
| `YES` | `println!("Yes");` |
| `NO` | `println!("No");` |
| `YN` | `println!("{}", if ok { "Yes" } else { "No" });` |
| `stdrb` | `let s = read_s().into_bytes();` |
| `stdr2` | `let [a, b]: [i64; 2] = read_vi().try_into().unwrap();` |

`ANS` / `YES` / `NO` は標準のRust構文の略記ではなく、**エディタで展開して使うもの**。スニペットを使わず、素直に `println!` を書いてもよい。`YN` の `ok` は、出力したい条件に置き換える。

## いつ proconio / Scanner を使う？

- **まず既存の行単位スニペット**：入力が読みやすい形で行ごとに与えられる問題。
- **入力の宣言が楽になるなら proconio**：AtCoderでグラフ・配列・`Usize1` を多用するとき。Cargoの依存関係が必要。
- **Scannerは補助的な選択肢**：外部クレート不可、かつ入力が行をまたぐなど `read_vi()` がつらいとき。[既存の実装](../templates/abc.rs) を使えるが、常用する必要はない。

問題のためのコードより入力ユーティリティのほうが長くならないようにする。
