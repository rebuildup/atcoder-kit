# 入出力：必要なコードをすぐ使う

入力は基本的に `read_i()` / `read_vi()` / `read_s()` を使う。関数定義は[スニペット](../スニペット.md)の `stdri` / `stdrvi` / `stdrs` で展開する。[提出テンプレート](../template.rs)には空の `main()` だけが入っている。

## 目的から探す

| したいこと | 使うコード | スニペット・条件 |
| --- | --- | --- |
| 整数を1つ読む | `let n = read_i();` | `stdri`：整数1個を1行で受け取る |
| 1行の整数列を読む | `let a = read_vi();` | `stdrvi`：スペース区切り |
| 文字列を読む | `let s = read_s();` | `stdrs`：1行の文字列 |
| バイト列として読む | `let s = read_s().into_bytes();` | `stdrb`：`read_s()` が必要 |
| 1行の整数2個を分ける | `let [n, y] = read_vi().try_into().unwrap();` | `stdr2`：ちょうど2個のとき |
| 結果を出力する | `println!("{ans}");` | `ANS`：変数名を展開 |
| Yes/Noを出す | `println!("{}", if ok { "Yes" } else { "No" });` | `YN`：条件式を展開 |

## 整数を別々の変数で受け取る

`read_vi()` が返す `Vec<i64>` を、要素数が決まった配列に変換する。

```rust
let [n, y] = read_vi().try_into().unwrap();
```

**入力が2個ちょうどと保証される場合**に使う。数が違えば `unwrap()` で失敗する。値を添字として使うときだけ `usize` に変換する。

```rust
let [l, r] = read_vi().try_into().unwrap();
let (l, r) = (l as usize - 1, r as usize - 1);
```

この例は入力の `l` と `r` が **1以上の添字**で、0-indexedへ変換する場合。単なる整数の計算なら変換しない。

## 文字列をバイト列で扱う

入力された文字列を `String` として使わず、英数字をバイト単位で処理する場合：

```rust
let s = read_s().into_bytes();
```

`into_bytes()` は `String` を `Vec<u8>` に変換する。UTF-8では日本語などの文字数とバイト数は異なるので、文字単位で扱う問題にはそのまま使わない。

`ends_with()` や `truncate()` を使って **Stringのまま末尾を処理する**例は、[末尾からの文字列分割](../アルゴリズム/文字列/末尾からの分割.md)にある。

## 答えを出力する

```rust
println!("{ans}");
println!("{}", if ok { "Yes" } else { "No" });
```

使うスニペットは `ANS`（変数名）、`pl`（式の値）、`YN`（Yes/No）。メソッド呼び出しなどの式は `println!("{}", d.len());` のように書く。

## 入力形式が違う場合

`read_i()` は1行から整数1個、`read_vi()` は**1行**から整数列を読む。複数行にまたがる配列・複雑な入力には [proconioの入力例](../templates/proconio.rs)や[Scanner](../templates/abc.rs)を使う。
