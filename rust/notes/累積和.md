# 累積和：まず短く書く、必要なら意味を確認する

**区間の合計や条件に一致した回数を、何度も高速に調べたい**ときに使う。

## 1. 一番よく使う形（整数の区間和）

```rust
let n = a.len();
let mut p = vec![0i64; n + 1];
for i in 0..n {
    p[i + 1] = p[i] + a[i];
}

// 半開区間 [l, r) の和
let sum = p[r] - p[l];
```

- `p[0] = 0`。`p[i]` は「先頭から `i` 個」の合計。
- 要素の区間が `l` 以上 `r` 未満なら `p[r] - p[l]`。
- 構築 `O(n)`、問い合わせ1回 `O(1)`。合計が `i64` に収まることが前提。

## 2. 値ではなく「条件を満たす回数」を数える

```rust
let mut p = vec![0usize; n + 1];
for i in 0..n {
    p[i + 1] = p[i] + usize::from(a[i] > 0);
}
```

これは「`a[i] > 0` なら1、そうでなければ0」を足す。`usize::from(bool)` が読みにくいなら `if` で書いても同じ。

```rust
p[i + 1] = p[i];
if a[i] > 0 {
    p[i + 1] += 1;
}
```

**短さと自分の読みやすさは別**。条件が長いなら、この `if` 形式のほうが見直しやすい。

## 3. 文字列の一致開始位置を数える（実戦例）

`s` の `i` 文字目**から** `t` が一致する回数を累積するなら:

```rust
let n = s.len();
let m = t.len();
let mut p = vec![0usize; n + 1];

for i in 0..n {
    p[i + 1] = p[i];
    if i + m <= n && &s[i..i + m] == t {
        p[i + 1] += 1;
    }
}
```

この `s` と `t` は**バイト列**（`&[u8]`）を想定し、`m > 0` とする。

問い合わせ区間が両端を含む `[l, r]`、パターン長が `m` なら、**開始位置として許される最後の位置**は `last = r - m + 1`。`r - l + 1 < m` の場合は一致しない。

```rust
let found = if r - l + 1 < m {
    false
} else {
    let last = r - m + 1;
    p[last + 1] > p[l]
};
```

`p` は減少しないので、`p[last + 1] - p[l] > 0` と書かずに比較してもよい。`l` / `r` を1-indexedから0-indexedへ変換する場所に注意する。
